# V1：把文档做好

状态：P1 / P2 本机阶段出口通过；P3-01～P3-06 的附件、搜索、历史/回收站、Docker 部署/账号维护、完整备份恢复和桌面日用/性能基线已有本机验收。实机手机按用户决定跳过，外网验收（P3-07）已放弃，NAS 未验收。备份目前使用可配置本机目录，S3 和自动调度未接入。表内列出 V1 目标，不表示后续功能已交付；实际证据见 [验证记录](../validation.md)。

2026-10-25 补充：V1 先供用户个人使用，预留多人能力。先提供初始账号及个人工作区的认证授权，不包含成员邀请、共享权限配置或多人管理界面。单人使用同样需要处理多标签与跨设备冲突。

同日确认：文档以页面树组织，一篇页面可以包含子页面；V1 不另设只能分类的文件夹类型。移动页面时子树随之移动，不能把页面移到自身或其子页面之下。

历史与回收站初期策略已确认：每次成功保存保留历史，暂不自动清理。恢复历史生成新修订，恢复前内容仍保留；页面、历史与附件的后续保留上限须按空间样例另行决定。

## 1. 范围

第一版可作为日用自部署笔记工具：创建和组织文档、顺畅写作、查找内容、导入导出、可靠保存及恢复。默认不依赖第三方云服务和收费插件。

| 能力 | V1 目标 |
| --- | --- |
| 组织 | 子页面树、创建、重命名、移动整棵子树、最近打开、删除与回收站 |
| 编辑 | 标题、段落、加粗/斜体/删除线、列表、待办、引用、代码、链接、分割线、普通表格；斜杠命令、代码高亮/行号/复制、行内与块级公式（2026-11-03 新增，见 [编辑打磨需求](editing-commands.md)） |
| 图片与附件 | 上传、展示/下载、稳定引用、大小限制、删除策略与备份 |
| Markdown | 常用语法快捷输入、md 导入导出、只读源码查看 |
| 写作体验 | 中文输入法、粘贴、选择、撤销/重做、快捷键、可读排版 |
| 保存 | 自动保存状态、串行更新、断线草稿恢复、切页不丢内容 |
| 冲突 | 跨设备/标签修订检查，冲突时保留本地内容并提供重新加载或另存副本 |
| 检索 | 标题与正文搜索，单独验证中文匹配质量 |
| 恢复 | 历史版本、回收站、数据库和附件一致备份/恢复 |
| 自部署 | Docker、持久化配置、初始化个人账号、登录和工作区级服务端授权；认证先于真实文档 API 接入 |

应用特有内容用结构化 JSON 保存，Markdown 不承担白板、数据库和完整历史的无损表示。V1 不实现这些复杂嵌入，但文档格式要有版本号和明确不支持项。

## 2. 暂缓

多维表格、业务数据迁移、双链关系图、块引用、白板、实时共同编辑、完整离线同步、桌面壳、AI、日程提醒和完整项目管理。简单页面双链另作后续小阶段，不阻塞文档基本体验。

公开链接分享不是默认承诺；先完成登录访问。是否开放匿名分享，在需求明确后单独设计授权和撤销。

页面树组织方式已在 P1 确认；视觉参考为 Docmost / Notion，桌面核心写作体验已有人工与浏览器复核，实机移动端仍待验证。任务依赖和阶段出口见 [实施计划](../plan.md)。

## 3. 关键验收

- **输入**：中文拼音选词与输入法回车不会误切块；光标和选区稳定；连续撤销/重做符合输入顺序。
- **粘贴**：纯文本、常用富文本、代码与图片的行为可预期，不静默丢失内容。
- **切页**：快速切换文档不会把旧请求结果显示到新文档，也不会把草稿写到错误对象。
- **保存**：区分编辑中、保存中、已保存、离线、失败和冲突；只有服务端确认后显示已保存。
- **冲突**：两个标签编辑同一文档时，较旧修订不能直接覆盖新内容；本地草稿可找回。
- **格式**：用固定 Markdown 样例验证标题、列表、引用、代码、图片和普通表格；不支持转换要提示并保留原内容。
- **身份**：文档 ID 在改名、移动、重启后不变；复制产生新 ID；引用块用显式持久 ID，不使用编辑器运行时 key。
- **恢复**：删除恢复、历史恢复、完整备份在新环境恢复都实际验证，附件随数据一起恢复。
- **权限**：未登录不能读写私人文档或附件；所有写入在服务端校验，不依赖前端隐藏按钮。
- **体验**：键盘可操作、焦点可见、空/错误状态完整；手机至少能阅读和基础导航。

## 4. 性能验收方法

建立小文档、长文档、图片文档及多文档集合，记录真实设备上的输入、打开、滚动、搜索、内存和服务端响应。书写过程不应被网络保存阻塞。具体数字在基准建立后确认，不复制旧报告未经复现的数据。

未来 25,000 条业务记录另做真实字段和查询的分页/索引验证，不以一次载入全部行的演示作为验收。

## 5. 正式使用门槛

文档可用、保存可恢复、权限真实有效、Docker 持久化验证通过后，才进入私人试用。外网访问的 HTTPS、反向代理、登录会话和附件授权验证（P3-07）已于 2026-11-03 按用户决定放弃，因此外网访问不属于已验收能力。首轮试用用非唯一副本，不能直接替代现有业务数据源。
