# 日历与外部日历同步

2026-11-16 用户确认需求，实现尚未开始。各期开工时，把接口和数据契约写进 architecture 目录，验证结果记入 [验证记录](../validation.md)。标为“提案”的条目是助手的建议，开工前还要确认。

## 1. 已确认的决定

| 事项 | 决定 |
| --- | --- |
| 形态 | 增强多维表格的日历视图，另加侧栏入口的全局日历页，聚合多个来源 |
| 事件的存放 | 事件就是多维表格的行（行即页面）。导入或订阅来的外部事件也落成某个数据库的行 |
| 外部接入方式 | `.ics` 文件导入、ICS 链接订阅（只读）、CalDAV 双向同步、Google / Outlook 的 OAuth 接入，四种都要 |
| 外部日历来源 | Google 日历、Outlook / Exchange、iCloud / Apple、飞书 / 钉钉 / 企业微信 |
| 首批能力 | 时刻、时长与跨天；周视图、日视图与日程列表；重复事件（包括在 NBase 里创建）；浏览器提醒 |
| 交付节奏 | 分三期，每期检查通过后提交：一期本地日历、导入和订阅；二期 CalDAV；三期 OAuth |
| 双向冲突 | 同一事件两边都改过时，保留两份并提示，由用户选择，不静默覆盖 |
| 写回范围 | 只有同步日历数据库的行会写回外部日历；其他数据库只在 NBase 内显示 |

## 2. 一期：本地日历、导入与订阅

**日期字段升级**

- 支持全天和定时两种，以及开始、结束（时长和跨天）。
- 现有只有日期的值继续有效，按全天单日处理。
- 筛选、相对日期、排序、页脚统计、公式、CSV 导入导出和各视图的单元格都要适配新的值。
- 按读者时区显示，沿用现有的时区回退规则。

**数据库日历视图**

- 有月、周、日三种视图和日程列表。
- 跨天事件横跨显示。在周视图和日视图的时间轴上，拖动改时间，拉伸改时长，点空白时段新建。

**全局日历页**

- 在侧栏有固定入口。
- 可以显示的来源：工作区内任意数据库的日期字段（每个来源单独开关、单独设颜色）、每日笔记、同步日历数据库。
- 点事件打开对应的行页面，点日期可以打开当天的每日笔记。
- 只加载可见时间范围内的数据。

**重复事件**

- 展开外部日历的重复规则（RRULE），包括 EXDATE 排除日期和 RECURRENCE-ID 单次例外。
- 可以在 NBase 里创建重复事件。编辑某一次时，可以选择只改这一次、这一次及以后，或者全部。

**浏览器提醒**

- 可以给事件设置提前多久提醒。
- 只有 NBase 页面开着、并且已授予通知权限时才会弹出。不承诺页面关闭后的推送。

**`.ics` 导入**

- 导入到新建的或已有的同步日历数据库。
- 按事件 UID 去重，重复导入不会产生重复的行。
- 再次导入时，如果某行在本地改过，按冲突规则处理（保留两份并提示）。

**ICS 订阅（只读）**

- 服务端定时拉取，复用网页书签的抓取防护，例如不允许访问内网地址。
- 显示上次同步的时间和失败原因。
- 同步来的字段只读。
- 提案：外部删除的事件，对应的行进回收站，可以恢复。

## 3. 二期：CalDAV 双向同步

- 一个同步日历数据库对应一个外部日历，只有这个库的行双向同步。
- 冲突时保留两份并提示，与现有文档的冲突处理保持一致。
- 外部账号的凭据在服务端加密保存，纳入备份恢复和账号维护说明。
- 提案：先用 iCloud（应用专用密码）验证。飞书、钉钉、企业微信是否提供 CalDAV，需要逐家核实。

## 4. 三期：OAuth 接入

- 接入 Google Calendar API 和 Microsoft Graph。Outlook / Exchange 不支持 CalDAV，双向同步只能走这一条。
- 由用户自己在 Google 或 Microsoft 后台注册 OAuth 应用。
- 在不开放外网的前提下，用哪种授权方式（localhost 回调或设备码），开工前要核实官方文档。

## 5. 同步日历数据库

- 每个外部日历或导入文件对应一个数据库。
- 同步字段由同步过程维护，包括标题、开始、结束、全天、地点、说明、重复规则、外部 UID 和来源。只读订阅时这些字段锁定；双向同步时可以编辑，并会写回外部。
- 用户可以加自己的字段（关联、标签、单选等）和行正文。这些内容不写回外部。
- 历史、回收站、搜索和双链都沿用页面的那一套。

## 7. 开工前要核实

- OAuth 的回调要求、Google 设备码流程是否允许日历权限、Google 应用停留在“测试”状态时刷新令牌的有效期。
- 飞书、钉钉、企业微信各自对 ICS 订阅和 CalDAV 的支持情况。
- ICS 解析和 RRULE 展开所用开源库的许可证与版本，引入时锁定版本。
- 容量：按可见范围查询和现有“每月最多 1000 行”上限的关系，以及重复事件展开数量的上限。
- 时区数据：ICS 里 VTIMEZONE 的处理方式。
