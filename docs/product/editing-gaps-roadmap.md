# 编辑体验补齐计划（N16～N27）

日期 2026-11-06。状态：**用户已确认第 4 节 D1～D4 的建议。F～J 批代码已交付，自动检查和演示工作台实测通过；I 批的 `test:db` 和 v11→v12 升级已在便携 PostgreSQL 上通过，只剩依赖 Docker 的备份恢复演练，见[验证记录](../validation.md)**。本文不表示功能已交付；交付状态记入 [实施计划](../plan.md)，证据记入 [验证记录](../validation.md)。

N01～N15 交付后，V1 的功能清单已基本覆盖，保存、冲突、历史和恢复链路也较完整。差距集中在日常编辑手感：列表缩进、链接、块操作、图片和页面排序。本计划只补这些，不扩大到多维表格、白板、块引用、实时协作或 AI。

## 1. 现状依据

| 缺口 | 依据 |
| --- | --- |
| 列表无法缩进 | 演示工作台实测：列表项内按 Tab，焦点跳到「折叠章节」按钮，未产生嵌套。代码没有调用缩进命令，工具栏没有缩进按钮。Markdown 导入支持嵌套列表，支持矩阵仍写着“待缩进交互验收” |
| 链接只能写不能用 | 未注册 `ClickableLinkPlugin` 和 `AutoLinkPlugin`，也没有链接悬浮卡片；`AutoLinkNode` 已注册，服务端已接受 `autolink`。此项来自代码，未实测 |
| 没有浮动工具栏、块手柄和块菜单 | 编辑器源码中没有对应插件，`draggable` / `onDragStart` 无匹配 |
| 图片只能原样显示 | `AttachmentNode` 只有 `attachmentId`、`alt`、`fileName`、`mediaType`，且是行内节点 |
| 页面不能手动排序 | 同级页面按 `created_at, id` 排序，没有排序字段；页面树没有拖拽 |
| 演示文案不符 | [fixtures.ts](../../apps/web/src/workspace/fixtures.ts) 提到阅读模式和专注模式，代码中都不存在 |

`@lexical/react` 0.52（MIT）已包含 `LexicalTabIndentationPlugin`、`LexicalClickableLinkPlugin`、`LexicalAutoLinkPlugin` 和 `LexicalDraggableBlockPlugin`，F、G 批不需要新增依赖。

## 3. 需求与验收

### F 批：修复基础操作

**N16 列表缩进**

- 在列表项和待办项内，Tab 增加一级缩进，Shift+Tab 减少一级。工具栏在光标位于列表时提供同样的两个按钮。
- 列表符号按嵌套层级循环：无序依次为实心圆、空心圆、方块，有序依次为数字、小写字母、小写罗马数字；层级按所有列表祖先计数，混合嵌套时同样适用。HTML 导出用同样的规则，Word 导出原本就按级别循环。
- 不直接启用 `TabIndentationPlugin` 的全局行为：普通段落缩进无法用 Markdown 表达，`sourceEditing.ts` 会把非零 `indent` 视为不可表达的属性。改为自定义 `KEY_TAB_COMMAND`，只在列表内接管。
- 列表外的 Tab 保持键盘焦点移动，代码块和表格沿用现有处理。斜杠菜单、页面引用菜单和输入法组词期间不触发缩进。
- 缩进层级上限定为 6 级，同时低于服务端 64 层深度限制。
- 2026-11-15 用户确认扩展：段落和标题内 Tab / Shift+Tab 整体缩进，最多 5 级，工具栏两个按钮同样可用。Markdown 用 `<div style="margin-left:2em">`（每级 2em）包住段落或标题，与对齐共用同一个 `<div>`，源码面板可应用。回车拆出的新段落沿用原缩进，行首 Backspace 减一级。引用块、代码块、表格单元格和折叠块摘要不缩进，这些位置以及无可缩进内容时 Tab 仍移动焦点；正文处于最左时 Shift+Tab 不再移出正文。转为引用或代码块时清除缩进和对齐。
- **验收**　三层混合有序、无序、待办的缩进和反缩进；一级项 Shift+Tab 不丢内容；多选列表项整体缩进；一次操作一个撤销步骤；保存刷新后层级不变；Markdown 导出再导入层级不变，源码面板可应用。

**N17 链接交互**

- 只读视图单击打开链接；编辑状态按决策 D3 打开。一律新标签，带 `noopener noreferrer`，继续经 `isSafeLinkUrl` 校验。
- 光标进入或悬停链接时显示卡片：地址、打开、复制、编辑、移除，只读时只有打开和复制。卡片内直接编辑地址，不用把视线移到页面顶部的工具栏表单。
- 输入网址后按空格或回车、或粘贴单个网址时，自动成为链接。代码块、行内代码和公式内不转换。选中文字后粘贴网址，为所选文字加链接。
- **实现决定**　不使用 `AutoLinkPlugin`：它通过全局节点变换工作，只打开含裸网址的旧页面也会改动正文，违反“打开页面不产生修订”。改为由按键和粘贴命令触发，生成普通 `link` 节点，已存的裸网址保持文字。
- **已知限制**　网址紧跟中文标点时（如 `https://a.com。`）不自动转换，因为没有空格或回车触发；可用工具栏或粘贴。
- **验收**　打开含裸网址的页面再切走，不产生新修订；`javascript:` 等危险协议不可打开；撤销一次可还原自动链接；自动链接的 Markdown 往返结果与矩阵一致；查找替换不改链接地址。

**N18 斜杠插入图片和附件**

- 增加 `/图片`、`/附件` 命令，打开现有文件选择器，上传成功后插入到触发位置。
- 文件选择器目前在 `PersistentWorkspace` 中，需要由编辑器 props 传入回调。演示模式没有上传能力，不显示这两个命令；只读和表格规则沿用现有上传逻辑。
- **验收**　取消选择时触发文字被清理且正文不变；上传中切页不写入新页面；上传失败有提示；一次操作可撤销。

**N19 演示文案**

- F 批先把欢迎页的阅读模式、专注模式文字改成当前实际能力。N26 交付后再按实际行为更新。

### G 批：块操作

**N20 浮动工具栏**

- 选中文字后在选区上方显示：粗体、斜体、删除线、高亮、行内代码、链接。操作与顶部工具栏共用同一组函数，状态保持一致。
- 输入法组词、只读、代码块内和表格多格选择时不显示。窄屏不显示，继续使用顶部工具栏。
- **验收**　不抢焦点、不改变选区；靠近视口边缘时不被裁切；滚动时跟随或收起；深色主题可读；实体输入法下不闪烁。

**N21 块手柄与块菜单**

- 悬停顶层块时左侧显示手柄，拖动可重排。点击打开菜单：转换类型、复制、上移、下移、删除。提供键盘替代 `Alt+Shift+↑/↓`。
- 没有使用实验接口 `LexicalDraggableBlockPlugin`：它的定位写死了内边距，也不认识折叠章节。改为自写 `BlockHandlePlugin`，移动逻辑在 `blockActions.ts`。首版只处理顶层块，列表项和表格行不拖动。
- 需要处理的结构：折叠章节拖动时带上隐藏内容或先展开；脚注定义只能留在顶层；复制含脚注的块时不能产生重复脚注定义；表格、Mermaid、公式和附件块可整体移动。
- **验收**　移动后撤销一次完全还原；折叠状态下不丢内容；保存和 Markdown 往返顺序正确；只读模式无手柄；中文输入时手柄不干扰光标。

### H 批：图片

**N22 图片尺寸、对齐、图注和放大**

- 附件节点增加可选字段：宽度、对齐、图注。节点 `version` 保持 1：字段可选，未设置时不写入，只打开旧页面不产生修订；源码编辑也只接受版本 1 的节点。
- 服务端 `validate.ts` 校验字段范围和长度。图注进入 `search_text`，同步更新 `search-text.ts`。
- 图片选中后显示尺寸预设和拖动手柄；点击打开放大预览，只读和历史预览也可用。图片继续走同源授权地址，不引入外部加载。
- 粘贴和拖入流程不变。首版不做图片裁剪、图片并排和外部图片加载。
- **验收**　宽度在窄屏不溢出；旧页面重新打开无修订；历史恢复后属性保留；ZIP 导出再导入按 D1 的结果表现；源码面板编辑后属性不丢失；深色主题下图注清晰。

### I 批：页面排序

**N23 页面手动排序**

- 迁移 v12 给 `pages` 增加排序键，在迁移事务内按现有 `created_at, id` 回填，保持当前显示顺序。
- 排序键用间隔 1024 的整数，默认值来自序列，所有新建路径自动排到末尾；间隔用尽时只重排该组同级页面。`list` 和 `page-tree` 改用新排序；现有 `list` 的游标基于 `created_at, id`，需同步调整。
- 页面树支持拖动到同级位置或另一父页面下，并提供「上移」「下移」菜单作为键盘和手机入口。继续禁止移到自身或子页面下。
- 同级排序用幂等的 `PUT /pages/:id/position`（目标是“排在某页之后”），写入走工作区行锁，不产生修订（D2）。目标位置是绝对的，响应丢失后重试不会重复移动，因此不用操作收据；跨父页面先走现有移动再定位。历史恢复保留当前位置，回收站恢复按原位置尝试，原父页面不可用时落到新父级末尾。
- 备份引擎的表和摘要核对要覆盖新列。子树 ZIP 的 manifest 记录顺序，导入后保持。演示工作台同步支持。
- **验收**　v11 升级到 v12 后顺序不变，含空实例；并发排序不丢更新；响应丢失后同操作 ID 重试不重复；2000 页目录拖动不卡顿；**含 v12 的备份包实际恢复一次**（此前含 v11 的备份包尚未恢复验证，本批一并补上）。

### J 批：写作辅助

**N24 字数统计**　显示字数、字符数和估算阅读时长，有选区时显示选区字数。中文按字计，英文按词计。统计须防抖，不在每次按键调用完整 `getSnapshot()`。

**N25 打印和 PDF**　增加 `@media print` 样式和「打印」入口，隐藏外壳，通过浏览器另存 PDF。打印前展开折叠章节，确保授权图片、KaTeX 和 Mermaid 已加载。不做服务端 PDF，也不做 Word 导出。

**N26 阅读设置**　专注模式（隐藏侧栏和工具栏）、全宽切换、正文字号三档。存 localStorage，属于视图状态，不进入文档、草稿或修订。

**N27 块级快捷键**　`Ctrl/Cmd+Alt+0～3` 切换正文和标题，列表、待办、引用和代码块各配一个；`Ctrl/Cmd+/` 打开快捷键帮助。实现前核对与浏览器和中文输入法的冲突。

**验收**　字数统计在 720 KB 长文档下不影响输入；打印结果包含完整章节；阅读设置刷新后保留，且不产生修订。

## 5. 暂不纳入

下列项目有价值，但 Markdown 表达、数据模型或优先级未定，等 N16～N27 完成后再评估。2026-11-11 起，除历史版本搜索和评论外均已按用户要求交付，状态见 [实施计划](../plan.md) 的扩展批次。

| 项目 | 暂缓原因 |
| --- | --- |
| 折叠块（toggle） | 新增节点类型，Markdown 无标准语法，需先定往返方案 |
| 文字颜色、背景色、段落对齐 | 同上，且会让源码面板更多情况被阻止应用 |
| 表格拖动列宽、合并单元格 | 源码转换保护列宽属性，服务端拒绝合并单元格；需先改 GFM 往返约定 |
| 音视频、PDF 内嵌预览、网页书签卡片 | 需评估附件类型、大小和存储；书签卡片涉及服务端抓取外部网页，有安全影响 |
| 拼音搜索、分词相关度、历史版本搜索 | 现有性能基线够用，需求明确后再改搜索方案 |
| HTML 和 Word 导出 | N25 先覆盖打印和 PDF，有实际需求再做 |
| 评论 | V1 面向个人使用 |

## 6. 通用完成标准

- 每批结束运行 `npm run check`，失败先修复。涉及迁移或服务端的批次另跑隔离库 `test:db`。
- 每批用 Edge 做浏览器实测，并在 [验证记录](../validation.md) 写明环境、结果和未验证项。自动化组合事件不能替代实体输入法。
- 所有批次都要回归：只打开并切页不产生修订、切页不串内容、撤销粒度、深色主题、窄屏布局、只读和历史预览。
- 影响 Markdown 行为时同步更新 [支持矩阵](markdown-support.md) 和固定样例；影响架构时在检查通过后更新 AGENT.md。
- 不新增依赖；确需新增时核对许可证并锁定版本。

**需要用户配合：** 实体中文输入法候选操作仍未人工复测，F、G 批完成后各复测一次。N20、N21 对输入法影响最大。
