# 文档编辑打磨：斜杠命令、代码块与公式

日期：2026-11-03。用户确认的需求与验收标准。本文是目标，不表示已交付；实际证据见 [验证记录](../validation.md)。

## 1. 斜杠命令

- **触发**：在段落开头或空白字符后键入 `/` 或中文输入法的 `、` 弹出命令菜单。紧跟非空白文字的 `/`、`、`（如「苹果、香蕉」、`a/b`）不触发。代码块内、行内代码格式内和只读模式不触发。
- **关键词**：触发符后的文字按命令的中文名称和英文别名做不区分大小写的匹配（如 `/标题`、`/h1`、`/代码`、`/code`、`/公式`、`/math`）。关键词前缀匹配排在前面。不做拼音匹配。没有匹配项时菜单关闭，已键入的文字保持为普通文字。
- **命令**：正文、标题 1-3、项目列表、编号列表、待办列表、引用、代码块、分割线、表格、块级公式、行内公式。执行后删除触发符和关键词；块样式与工具栏「段落样式」采用相同规则。在表格内不提供「表格」和「块级公式」。
- **键盘**：↑/↓ 移动选择，Enter 或 Tab 执行，Esc 关闭并保留已键入文字；可以用鼠标点击执行。中文输入法正在组合时按回车只确认候选词，不执行命令。
- **可访问性**：菜单使用 listbox/option 语义，当前项可见；菜单不能超出视口。

## 2. 代码块

- **高亮**：使用 `@lexical/code-prism`（Prism，MIT），在 Prism 默认语言之外补充 Bash/Shell、JSON、YAML、Go。代码块提供语言选择，含「纯文本」。Markdown 导入的常见别名（`js`、`ts`、`sh`、`shell`、`yml`、`py`、`html` 等）映射到对应语言；不认识的语言名保留原值，导出时原样写回，按纯文本显示。
- **行号**：每个代码块显示行号；行号不进入复制内容、Markdown 或正文 JSON。
- **复制**：代码块提供「复制代码」按钮，只读模式（历史/回收站预览）也可用，成功或失败都给出提示。
- **编辑**：光标位于代码块内时，工具栏下方显示代码操作行（语言选择、复制），可用键盘操作；代码块内 Tab / Shift+Tab 缩进或取消缩进。
- **持久化**：高亮产生的 `code-highlight` 分词节点只用于显示。保存、草稿和比较使用规范化的代码内容，只打开或切换含代码块的页面不能产生新修订；页面大小限制不因高亮而增加。

## 3. 公式

- **渲染**：使用 KaTeX（MIT），字体和样式随网页打包，不请求外部 CDN。禁用 `trust`，`\href` 等命令不会生成可点击链接或外部请求。
- **类型**：行内公式和块级公式。块级公式独占一行，不能放在表格单元格内。
- **插入**：可以使用斜杠命令；键入 `$源码$` 时自动转换为行内公式，在空段落中键入 `$$` 并回车时生成块级公式。新插入的空公式自动打开编辑框，取消时删除空公式。
- **行内 `$` 规则**：开头 `$` 后面和结尾 `$` 前面必须是非空白字符，结尾 `$` 后面不能紧跟数字，`\$` 不触发转换。因此「价格 $5 到 $10」保持为普通文字。转换后撤销一次可以找回原输入文字。
- **编辑**：点击公式或选中公式后按 Enter，打开 LaTeX 源码框，下方显示实时预览。行内公式按 Enter 确认，块级公式按 Ctrl+Enter 确认，Esc 取消；中文输入法组合时的回车不确认。确认时源码为空则删除公式。一次确认产生一个撤销步骤。只读模式只显示渲染结果。
- **错误**：LaTeX 有误时，预览显示错误信息；正文中以醒目样式显示原始源码，不丢失内容。
- **Markdown**：导出行内公式为 `$源码$`，块级公式为独立的 `$$` 围栏。导入时 `$…$`（适用上述规则）和 `$$…$$`（单行或多行）转换为公式。导入时 `\(…\)`、`\[…\]` 和未闭合的 `$$` 块仍按现有规则整篇保留为原文并给出提示。普通文字中的 `$` 导出为 `\$`，往返后不会变成公式。
- **搜索**：公式源码进入服务端全文搜索；打开结果后定位到对应公式。
- **服务端**：新增 `equation` 节点类型，必须包含字符串源码（有长度上限）和布尔类型的行内标记；其他字段沿用现有校验规则。

## 4. 不在本轮范围

拼音匹配、Callout、Mermaid 图表、Shiki 高亮、公式所见即所得编辑、`\(…\)` 和 `\[…\]` 导入，以及斜杠菜单中的上传附件命令。

## 5. 验收

- 自动测试覆盖：触发与不触发的条件、关键词过滤、命令执行结果、代码规范化与「打开再切页不产生修订」、语言别名的导入导出往返、公式节点 JSON 再打开、行内/块级 `$` 转换与不转换的样例、`\$` 往返、Markdown 导入导出、服务端校验与搜索提取。
- 浏览器实测（Edge）：斜杠菜单的鼠标/键盘操作、中文输入法（可通过 CDP `Input.imeSetComposition` 模拟）组合中回车、代码高亮/行号/复制、公式编辑框、撤销/重做、刷新后重新打开的内容一致性、只读预览。
- 构建后检查 KaTeX 字体由本站提供，构建没有新的体积警告，`npm run check` 通过。
