# NBase Markdown 编辑与笔记功能需求及实施计划

日期 2026-11-04（Asia/Shanghai）。用户已确认纳入下列功能。N01～N15 均已交付，各批状态见 [实施计划](../plan.md#markdown-与笔记迭代)，证据见 [验证记录](../validation.md)。编号表示依赖和交付批次。下文保留为当时的需求与验收基线，实际行为以 [支持矩阵](markdown-support.md) 和代码为准。

本轮承接 P3 本机验收后的文档打磨，并纳入原 P4 的简单页面双链。已有页面树、个人工作区、斜杠命令、全文搜索、附件、修订与恢复链路作为实现基础。Lexical JSON 继续保存正文，Markdown 用于导入、导出、查看及受支持范围内的源码编辑。原阶段状态和验证证据分别见 [实施计划](../plan.md) 和 [验证记录](../validation.md)。

## 1. 页内编辑与阅读

### N01 页内查找与替换

- 通过 `Ctrl/Cmd+F` 打开当前笔记内的查找栏（工具栏不设查找按钮），显示命中总数和当前位置，支持上下循环跳转。查找范围为标题及正文中的可见文字，代码块按原文查找。首次交付按字面量匹配，支持大小写开关。中文输入法组词期间保留输入，确认候选后再更新结果。
- 可替换当前或全部命中。标题和正文的替换都走已有编辑和保存链路。替换保留未命中文字及其格式，不跨段落或单元格边界，不修改链接地址、公式源码和附件属性。无法安全替换的匹配项仍可定位，界面解释限制。只读视图可查找。
- **验收**　中文、中英混排、跨相邻格式的命中都可定位。快速切页清除旧结果，查找本身不产生新修订。全部替换可整体撤销，空查询不可执行替换。

### N02 提示块

- 通过 `/提示` 插入备注、注意或结论块，支持可选标题以及段落、列表、链接等常用内容。在提示块内右键可更换类型、修改标题、转换回普通正文。在正文编辑、只读预览、历史和回收站里均可辨认类型。
- 定义一组可往返的 Markdown 引用标记，例如 `> [!NOTE]`、`> [!WARNING]` 和 `> [!IMPORTANT]`。用户自定义标题的表达方式在实现时与样例一起冻结。未知标记保留原文字和引用结构。
- **验收**　空块可直接输入和退出，已有引用可转换，撤销后内容完整。导出再导入可恢复类型、标题及正文，搜索能匹配块内的可见文字。

### N03 行内文字高亮

- 工具栏提供一种默认高亮色，可对选中文字添加或移除，与粗体、斜体及链接文字组合。浅色和深色主题均须清晰可读。
- 定义 NBase 支持的 `==文字==` 扩展及转义规则。围栏代码、行内代码和显式转义的等号按原样处理。
- **验收**　可用键盘选区和工具栏操作，刷新和历史预览后高亮仍在。中文、格式嵌套和字面等号的 Markdown 往返结果符合样例。

### N04 按标题折叠章节

- 标题旁提供折叠和展开按钮。折叠范围延伸至下一个同级或更高层级标题，包含其间的子标题。使用当前视图的标题定位能力，首版折叠状态仅在当前打开的页面会话中保留。
- 点击大纲或打开落在折叠区域内的查找结果时，展开相关章节并定位。折叠属于阅读状态，正文保存、复制、导出和搜索继续处理完整内容。
- **验收**　混合标题层级、末尾章节和连续折叠行为正确。移动焦点、阅读模式切换及展开不会产生内容修订或让正文丢失。

### N05 普通表格操作增强

- 将 Excel 或纯文本的矩形制表符数据粘贴到空段落时，提供转为普通表格的入口。粘贴到已有表格时从当前单元格填充，越界时预览扩展范围。识别空单元格、空尾列和不同换行格式。遇到无法安全解析或超出限制的内容时保留文本粘贴路径。
- 表格右键菜单支持单列左中右对齐、移动行和移动列，保留现有增删与键盘导航。首行继续遵循已有表头规则。粘贴只取单元格文本，不执行公式。
- **验收**　覆盖中文、空单元格、不齐列、超限粘贴和转义管道。一次矩形粘贴可整体撤销，移动操作保留单元格内容和对齐，导出保持现有普通 GFM 表格兼容范围。

## 2. 新建、记录与整理

### N06 笔记模板

- 新建时可选空白页、读书笔记、会议记录、排障记录或个人模板。支持把已有页面另存为个人模板，管理模板名称和正文。首版占位符限日期和新页面标题，创建前可预览。
- 应用模板时复制结构化正文到所选父页下的新页面。保留有效的同工作区附件引用，缺失引用在预览中提示。模板更新只影响以后从该模板创建的页面。
- **验收**　同一模板可生成多个互不影响的页面。检查中文标题、日期边界、附件授权和重复提交，确认重试只创建一次。

### N07 复制页面

- 页面菜单提供「复制页面」，默认在同一父页下生成带后缀的副本，可在创建前更改标题及位置。首版复制单页正文、图标、封面与标签。保留同工作区附件及页面链接的原目标。新页有独立 ID 和修订，历史、草稿、收藏及子页面由原页继续持有。
- 若原页存在未保存编辑，复制对话框说明使用的版本。首版要求先完成保存，遇到冲突或保存失败时保留原编辑并提示处理。
- **验收**　复制后可单独编辑和删除，附件仍能读取，重试不重复建页。viewer、越权父页及回收站中的源页不能发起复制。

### N08 标签与筛选

- 同一页面可关联多个工作区标签。支持创建、重命名、选择和移除标签，在工作台的页面列表和全库搜索中筛选。标签支持中文及中英文混排，去除首尾空白。同名判定、长度和数量上限在契约中固定。
- 首版多标签使用「同时包含」。重命名后原关联继续有效，删除标签只解除关联，回收站中的页面从活动列表和搜索中排除，恢复后有效标签重新出现。
- **验收**　覆盖中文标签、同名冲突、改名、组合查询及删除恢复。搜索结果、数量及标签列表均受工作区权限约束。

### N09 每日笔记

- 提供「今天」入口，在指定父页下打开或创建当前日期的笔记。首版允许指定日期和选择模板，默认标题使用 `YYYY-MM-DD`。日期按工作区配置的时区计算，日期身份独立于标题和目录位置。
- 同工作区同一天最多一篇活动每日笔记，服务端处理多标签同时创建。若当天笔记在回收站，提示恢复原页，避免快捷入口无提示创建同日副本。
- **验收**　重复打开、并发创建和请求重试返回同一个页面。覆盖时区跨午夜、改名或移动后仍可打开，以及回收站中的当天页面。

### N10 快速记录

- 在工作台提供「快速记录」入口，提交一条纯文本到当天笔记的「随手记」小节，并显示成功、等待或失败。小节缺失时创建一次，定位使用持久标识，改名不生成第二个小节。
- 网络失败保留待提交文字。服务端追加沿用修订检查、历史和幂等收据。同页有未保存编辑时先合并到同一保存流程或等待保存完成，冲突时保留文本并给出重试入口。
- **验收**　当天笔记缺失时也能记录，连续提交、双标签同时追加或响应丢失重试均不会覆盖已保存正文或重复插入。

## 3. 页面引用与反向链接

### N11 简单双链

- 输入 `[[` 后按标题和父路径搜索可访问的活动页面。选中后插入有稳定页面 ID 的引用，可编辑显示文字。同名候选显示父路径，保存后移动或改名仍可打开。目标进入回收站时显示失效状态，目标恢复后可重新打开。
- 目标页提供反链列表，显示引用来源页及正文片段，支持跳回引用处。索引从已保存正文派生，与页面修订同步，历史恢复、页面删除和恢复都应同步结果。读取反链前检查来源与目标的访问权限。
- 导出时生成可读的 Markdown 链接。单页导出提供稳定链接及显示文字，集合内导入导出涉及相对路径时按集合映射转换。已有笔记里的 `[[标题]]` 仅在目标唯一且可访问时自动解析，歧义或缺失时保留字面原文并给出报告。块级引用、关系图及自动创建缺失页面后续另立范围。
- **验收**　覆盖同名页、重复引用、改名、移动、删除、恢复、历史回退和跨工作区隔离。草稿未保存时不进入反链索引。

## 4. Markdown 兼容、迁移与源码编辑

### N12 脚注、引用式链接与 front matter

- 脚注支持正文引用与文末定义、重复引用同一注释和阅读时来回跳转，导出保留可配对的标识。引用式链接的常见定义可被解析和导出为等价链接，重复或缺失定义给出提示。引用式图片依照既有远程图片和附件规则处理。
- 支持文首常见 YAML front matter，先定义 `title`、`tags`、`date` 的类型及其与文件名、页面字段和模板日期的优先级。未知键保留为可导出的元数据，避免导入时静默丢弃。使用安全解析和体积、嵌套限制。格式错误、歧义或不支持的结构沿用原文保全流程。
- **验收**　真实样例覆盖中文值、转义、重复标识、缺失定义、无效日期和代码块里的同形语法。导入报告说明保留或规范化的内容，导出再导入保留受支持的语义。

### N13 文件夹批量导入与附件重建

- 选择 Markdown 文件夹后先扫描并预览目录、页数、附件和异常。将目录映射为 NBase 子页面树。文件与目录同名时在预览中显示映射，保留相互可区分的页面。目标目录中已有同名页面时默认创建可区分的副本。
- 在所选根内解析相对链接和图片引用，先建立路径到页面 ID 的映射，再重建内部页面引用与附件。缺失文件、越界路径、重复路径和不支持的图片类型逐项报告。外部 URL 沿用已有的安全引用处理。复用现有附件大小、类型、授权和内容检查。
- 批次记录每项成功、待处理和失败状态，可取消尚未执行的项并重试失败项。对已完成的文件和附件复用原写入标识，报告可导出，用户可找到已创建的页面。
- **验收**　使用含中文文件名、空格、嵌套路径、同名文件、缺失图片和越界链接的样例。覆盖中途断线、部分完成后重试、权限失效及大批量上限。将现有单页附件 ZIP 解包后通过文件夹入口导入，可重建正文与附件关系。

### N14 Mermaid 图表

- 通过 `/图表` 或 `mermaid` 围栏插入，首版支持流程图和时序图。提供源码输入与预览，错误时显示诊断并保留源码。以原围栏导出，可从 Markdown 重新导入。
- 渲染组件按需加载并在自部署站点提供。限制输入体积、图形复杂度和渲染资源，禁止图表脚本、外链资源和交互指令。语法错误或达到限制时显示可复制的文本表示。
- **验收**　覆盖中文、无效语法、过大图表、潜在危险链接以及快速切页。编辑和只读模式结果一致，历史可查看，打开图表不产生内容修订或向外站发起请求。

### N15 Markdown 源码编辑

- 从已有源码面板进入编辑会话，初始文本来自当前正文。提供预览、应用、取消和复制源码。应用前解析受支持的语法并显示转换诊断，切换模式本身不修改正文。取消返回原文档状态，应用只产生一次编辑动作并进入原有保存流程。
- 维护明确的语义往返范围，覆盖基础格式、普通表格、代码、公式、附件及本计划新增且已交付的 Markdown 表达。正文节点与页面标题、标签等元数据的编辑边界单独标注。遇到无法表达的节点、失效附件、未知语法或有损转换时保留原文档及输入文本，并阻止会丢内容的应用。
- 源码编辑期间为当前页面保留独立草稿，按账号、工作区和文档隔离，记录基准修订。切页、刷新或会话过期后可恢复。服务端出现较新修订时沿用冲突处理，可复制或另存编辑内容。持久化格式继续遵循正文的版本化 JSON 契约，Markdown 往返以语义一致为准。
- **验收**　覆盖未修改源码退出、应用与撤销、两标签编辑、断线与刷新恢复。使用包含公式、表格、附件、双链、脚注和图表的混合样例，验证预览、应用、导出和重新导入的结果。任何诊断失败均保留可复制的输入与原正文。

## 5. 实施顺序与阶段出口

| 批次 | 任务 | 依赖与出口 |
| --- | --- | --- |
| A　编辑常用操作 | N01～N05 | 基于现有编辑器、表格和搜索定位能力。先冻结提示块与高亮的 Markdown 样例，再接入服务端校验、搜索提取和历史预览。用中英文长文验证查找及折叠。 |
| B　新建与整理 | N06～N10 | 先统一模板、复制和标签契约。复制标签依赖 N08；每日笔记可复用 N06 的模板创建，快速记录依赖 N09 的日期定位。用隔离 PostgreSQL 验证并发、重试、权限和恢复。 |
| C　页面关联 | N11 | 复用稳定页面 ID、搜索候选与软删除契约。确认反链更新路径和导出表达，并验证已有页面的数据迁移。 |
| D　格式与迁移 | N12～N14 | N13 依赖 N11 的页面引用映射及 N12 的元数据处理，Mermaid 可独立实现。用含附件、重复名称和断线重试的文件夹样例验收。 |
| E　源码编辑 | N15 | 以 A～D 的实际格式契约及测试样例为基础，先验证所有已支持内容的往返，再开放应用写入。 |

## 6. 通用验收与进度记录

- 保持页面 ID、修订检查、保存确认、草稿隔离、工作区授权与附件访问规则。新增结构化节点同步更新客户端和服务端契约、历史及回收站预览、搜索提取和 Markdown 能力矩阵。支持旧页面、历史快照和草稿读取。
- 需要新增持久化数据时，验证隔离 PostgreSQL 上的空库安装、旧库升级、备份清单及新环境恢复。可重建索引明确重建方式。模板、标签、每日笔记和附件引用等需恢复的数据纳入演练。
- 每批运行 `npm run check`，涉及数据库时另跑隔离 `test:db`。桌面浏览器按功能实测键盘、中文输入法、长文档、保存失败和快速切页。用已有 P3-06 样例比较长文输入与打开速度，检查新增扫描、索引或渲染的影响。
- 将实际结果和遗留问题记录到 [验证记录](../validation.md)，并在相应任务全部验收后更新 [实施计划](../plan.md) 的阶段状态。
