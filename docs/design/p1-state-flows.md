# P1 页面与状态说明

日期：2026-10-25。视觉参考为 Docmost / Notion；[独立 HTML 原型](../../designs/nbase-workspace/index.html)用于整体布局沟通，[React 工作台](../../apps/web/src/workspace/Workspace.tsx)用于真实编辑交互验证。用户已确认页面树：页面可以包含子页面，V1 不另设文件夹实体。

## 当前可操作路径

左侧页面树、工作台、最近访问、收藏与回收站都操作当前会话的示例内容。顶部提供阅读/编辑、Markdown 源码、收藏、专注与页面菜单。正文由 Lexical 编辑，标题由独立字段编辑；目录仅根据正文标题生成，会随正文更新。搜索匹配当前会话中的标题和正文。导入 `.md` 前显示风险与原文预览，须主动确认；导入原文保留在该会话页面中供下载。导出使用当前编辑快照和页面标题，源码面板只读。

所有操作均为前端内存状态。刷新或关闭会重置，页面持续显示提示；服务健康只说明进程可连接。会话内删除可从回收站恢复，刷新后不保留删除或恢复记录。下载 Markdown 是用户主动保留副本的途径，但复杂格式导出可能改变表示，原始导入文件应另行保存。

## 后续正式保存的视觉状态草案

| 状态 | 用户看到的文字与动作 | 触发来源 |
| --- | --- | --- |
| 正在打开 | 页面骨架、明确的加载提示；目录保留当前位置 | P2 文档读取 |
| 编辑中 | “有未保存修改”；允许继续输入 | 本地内容变更 |
| 保存中 | “正在保存…”；切页应保留该文档任务 | P2 写入请求 |
| 已保存 | “已保存”；只在当前最新修订获服务端确认后显示 | 服务端确认 |
| 离线 / 超时 | “暂时无法确认是否已保存”；保留正文、提供重试和导出 | 网络断开、无响应 |
| 写入失败 | “保存失败，本地内容仍在”；重试/导出，不能清空编辑器 | 服务错误、存储错误 |
| 修订冲突 | 双栏比较本地与服务器版本，允许复制与另存；禁止直接覆盖 | 409 冲突 |
| 草稿恢复 | 先预览浏览器草稿与服务端内容，再选恢复或另存 | P2 本地草稿发现 |
| 无权限 / 登录失效 | 原内容继续可复制导出，重新登录后重新核对修订 | P2 授权失败 |

以上 P2 状态是界面规范草案，当前没有业务 API 或持久化路径，不能在产品中模拟“已保存”。
