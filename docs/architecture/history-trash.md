# 历史与回收站契约

用户已确认：**每次成功保存留历史，暂不自动清理**。页面、历史、回收站与已提交附件都没有自动过期策略，也没有永久清空入口。后续按实际空间样例讨论保留上限，不能静默删除旧版本。

## 快照与恢复

- 迁移 v4 创建 `page_versions`，主键为 `(workspace_id, page_id, revision)`。快照包含标题、正文、格式版本、原父 ID、删除状态、保存时间、操作者和操作类型。
- 迁移只为已有页面保存当前状态的“迁移基线”，不增加页面修订或改更新时间。迁移前未保留的历史不能据此恢复。
- 创建、更新、删除/恢复子树、历史恢复的每个实际新修订，在同一事务中写入完整快照和操作收据。快照写入失败时整笔回滚；相同操作 ID 重试先返回原收据，不重复增加修订或历史。
- 历史恢复只恢复选中版本的标题和正文，保留当前目录位置与页面 ID。必须提供当前 `expectedRevision` 和 `sourceRevision`；来源版本号参与操作摘要。恢复生成新修订，恢复前的当前内容仍留在历史中。未知正文格式拒绝恢复，原 JSON 可下载。
- 历史和附件读取继续校验当前工作区成员身份；viewer 可预览、不能恢复。恢复不会绕过当前页面写权限。附件按稳定 ID 引用，旧版本附件继续保留。

## 回收站子树

删除将当前有效的选中页面及后代放入同一删除组。此前独立删除的后代保留原删除组。恢复任意选中页面时，仅恢复选中页面及同组后代，不恢复兄弟或独立删除的后代。原父页面不可用时，选中页面恢复到工作区根；内部后代父子关系和页面 ID 保留。同名页面并存，不按名称覆盖。

网页在确认删除时重新读取目录并检查目标子树中的本机草稿；目录变化时要求重新确认。提交包含 `expectedSubtreeIds`，服务端在工作区事务锁内比较实际子树，不一致返回 `PAGE_TREE_CHANGED`，避免预检后新移动进来的后代被一并删除。该字段在 API 中为可选兼容字段；网页始终提供，1～2000 个唯一 UUID。未提供的 API 调用使用提交时的实际子树。

## API

所有路径前缀为 `/api/workspaces/:workspaceId`，响应不缓存。读取要求会话和成员身份，变更另要求 Origin、CSRF 和写权限。

| 方法与路径 | 行为 |
| --- | --- |
| `GET /pages/:pageId/history` | 按修订倒序列摘要，`beforeRevision` 游标，默认 50 条、最多 100 条 |
| `GET /pages/:pageId/history/:revision` | 读取单版完整预览，已删除页面也可读取历史 |
| `POST /pages/:pageId/restore-version` | 使用操作 UUID、当前修订和来源修订恢复标题与正文 |
| `GET /trash` | 按删除时间和 ID 倒序分页，默认 50 条、最多 100 条，返回所有已删除页面而非仅删除组根 |
| `GET /trash/:pageId` | 读取已删除页面正文及删除组信息 |
| `POST /pages/:pageId/trash` | 使用操作 UUID、当前修订及可选子树核对移入回收站 |
| `POST /pages/:pageId/restore` | 使用操作 UUID、当前修订恢复选中同组子树 |

## 浏览器保护

恢复历史或删除前先等待目标页的在途保存，再确认最新草稿已保存；与现有草稿相同的编辑器状态不重复标记为新更改。其他标签/会话的未处理草稿、待确认创建和附件上传会阻止操作。其他设备尚未提交的编辑无法由本浏览器提前检查，仍依靠修订冲突、本机草稿及服务端快照保护。

IndexedDB v3 的 `pending-actions` 保存账号、工作区、页面、操作、预期/来源修订、子树范围与操作 UUID，落盘成功后才发送变更。超时或服务失败先查收据，结果未知时保留记录、暂停相关页面自动保存；刷新或重登后可用同一 ID 重试。明确未提交的拒绝释放该记录，让用户重新检查后发起新操作。读取本机记录失败会暂停网络写入，但允许继续输入和下载当前正文。

预览使用独立只读编辑器及页面/修订身份，不接主页面的保存回调。恢复成功重新读取当前服务端状态；旧收据不会直接替换编辑器，迟到响应也不会把已切换到另一页面的正文换回。历史与回收站不能代替数据库和附件的一致备份。
