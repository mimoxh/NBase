# 双链关系图

关系图展示**已保存到服务端且未进入回收站**的页面之间的引用关系。它是 `page_links` 索引的只读视图，不新增表或迁移，也不读取浏览器草稿：正文保存成功后，新链接才会出现在图中。

## 接口

`GET /api/workspaces/:workspaceId/graph`，需要有效会话和工作区成员身份，viewer 也可读取；返回 `Cache-Control: no-store`。无数据库配置时不注册此路由（404），未登录返回 401，不是成员或 ID 非法返回 404。契约在 `packages/contracts/src/graph.ts`：

```ts
interface WorkspaceGraphResponse {
  nodes: { id; title; icon; kind: 'document' | 'database'; parentId: string | null; tagIds: string[] }[];
  edges: { source; target; kind: 'page-reference'; count: number }[];
  truncated: boolean;
}
```

- **节点**：工作区内未删除的文档和数据库页面。数据库的行不单独成为节点，因为一个库可能有几千行；行正文里的链接计入所属数据库，指向行的链接也算作指向该数据库。`parentId` 只在父页面也在返回集合中时给出，行的子页面上移到数据库。
- **边**：按（来源，目标，种类）聚合 `page_links`，`count` 是引用次数。两端都必须是本工作区未删除的页面且都在返回的节点中；自引用和折叠后同一节点内部的链接不计。方向保留：A→B 与 B→A 是两条边，前端绘制时合成一条带双向箭头的线。
- **不包含**：多维表格关联字段（`database_row_links`）、行之间的关联、历史版本中的链接、浏览器草稿中的链接。父子层级不作为服务端边返回，前端按 `parentId` 生成可切换的“层级连线”。
- **上限**：最多 2000 个节点（`graphNodeLimit`，按 `updated_at DESC, id` 取最近更新的页面，与目录树上限一致）和 10000 条聚合边（`graphEdgeLimit`，按引用次数降序）。任一超限时 `truncated = true`，界面显示提示。两次查询都在 SQL 中以成员关系联结；边查询只在已选节点 ID 之间聚合。

### 新增链接种类

`apps/server/src/graph/graph.ts` 的 `linkSources` 是所有链接来源的 `UNION ALL`，每行只需（workspace_id, source_page_id, target_page_id, kind）。块引用等新索引加入时：在 `linkSources` 增加一个分支，在契约 `graphLinkKinds` 增加种类名。行折叠、活动状态、成员校验和聚合不需改动。前端 `model.ts` 的 `pairs()` 目前把所有种类的次数合并到同一条线，要分开显示时从那里拆分；`demoSource.ts` 需同步识别新节点类型。

## 网页

- `apps/web/src/graph/` 是独立 chunk，经 `lazy.tsx` 首次打开时才加载。`GraphView` 只依赖 `GraphSource { load(signal) }`：持久化工作台用 `persistentSource.ts` 请求上述接口；演示工作台用 `demoSource.ts` 从内存页面的编辑器快照派生，规则与服务端相同（活动页面、行并入数据库、去除自引用）。
- **全局关系图**：侧栏“关系图”或 `Ctrl/⌘+Shift+G` 打开大尺寸对话框。支持标题筛选、显示/隐藏孤立页面、层级连线、按顶层页面或首个标签着色（带图例）、局部模式和 1～3 层深度。点击选中并在侧栏显示链接到/被链接列表；双击、`Enter` 或列表按钮打开页面，一律经工作台原有切页流程（先保存或记录当前草稿）。悬停高亮邻居并淡化其他节点。拖动空白处平移，拖动节点时固定该节点，滚轮或双指缩放，“适应窗口”复位。画布获得焦点时方向键平移、`+`/`-` 缩放、`0` 适应窗口。侧栏列表是完整的键盘替代：未选中时列出连接最多的 40 个页面。
- **局部关系图**：页面正文下方、反向链接之后的可折叠区域（展开状态存 localStorage），显示当前页 1 或 2 层邻域和可点击的页面列表。数据库行页面显示所属数据库的邻域。页面修订变化后 1.5 秒防抖重新读取，读取期间保留旧图；返回内容与上次相同时不重建布局。
- **状态**：读取中、读取失败（可重试；有旧数据时继续显示旧图并提示）、没有页面、有页面但没有链接（说明输入 `[[` 创建双链，可先查看层级）、筛选后为空、超限提示。

## 布局与渲染

- 力导向布局为自写纯函数（`layout.ts`、`quadtree.ts`，不依赖 DOM，Vitest 覆盖）：Barnes–Hut 四叉树斥力（θ = 0.9，最小距离限幅，重合点按索引确定方向分开），连线弹簧（按两端度数削弱，重复引用略增强），向原点的引力，速度摩擦和上限，alpha 衰减到阈值后停止。
- **确定性**：初始位置由页面 ID 哈希决定；刷新或筛选改变时，已有节点沿用上次位置，新节点放在已定位邻居旁，只以较低 alpha 局部松弛，避免整体跳动。不超过 120 个节点的图在首帧前直接算完。
- **帧循环**：只在布局尚未静止或正在拖动时运行 `requestAnimationFrame`，每帧最多 4 步且不超过约 7 ms；静止后停止。页面隐藏或画布不在视口时暂停，可见后继续。
- **绘制**：`<canvas>`，按设备像素比（最多 2 倍）。连线按样式分桶，每桶一次 stroke；节点按颜色合并路径；视口外的线、节点和标签跳过。节点大小随度数，数据库画成方块；线宽随引用次数；箭头在缩放足够且可见线不超过 1500 条时绘制，悬停或选中时只画相关箭头。标签按度数从高到低、随缩放逐步出现，最多 320 个，并按粗网格避免重叠。颜色从 `--nb-*` 变量读取，`data-theme` 变化时重新读取，适配深浅色。
- ≤720px 时对话框全屏，画布在上、列表在下，图例隐藏，控件加高。

## 已知限制

- 前端每帧的斥力计算是 O(n log n)，2000 节点约 3 ms/步（本机 Chromium），首次打开大图需要数秒才能静止；节点位置只保存在当前会话内存中，刷新页面后从种子位置重新计算。
- 2000 个节点、5000 条边时整体视图会很密集，主要靠筛选、局部模式和缩放查看；没有聚类折叠。
- 标签着色只用页面的第一个标签。
- 局部关系图读取整个工作区图再在前端提取邻域；工作区很大时可改为服务端按中心页和深度查询。
- 演示工作台的链接只来自当前会话中打开过并生成快照的页面；示例内容没有双链时，默认显示层级连线。
- 尚未在真实 PostgreSQL 上压测 2000 页面的接口耗时，也没有为聚合查询新增索引；现有 `page_links` 主键以来源开头，聚合需要扫描该工作区的全部链接行。
