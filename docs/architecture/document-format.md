# P1 文档格式草案

日期：2026-10-25。这是编辑器验证所用的前端契约，尚未冻结为数据库或公开 API 契约。

## 内容与身份

`DocumentContent` 包含 `schemaVersion: 1` 和 Lexical `SerializedEditorState`。Markdown、纯文本和目录是从当前 JSON 派生的视图，不是独立的权威副本。运行时节点 key 只用于本次页面的目录定位，不作为业务 ID 或持久块引用。

工作台为每篇示例文档分配稳定的会话内 ID。编辑器以文档 ID 作为 React key，每次切换加载该文档自己的初始状态；编辑回调同时携带文档 ID，防止旧回调写入新页面。切换、查看源码和导出前读取当前最新快照。初次加载的 onReady 不应计为用户修改。

用户已确认页面可包含子页面。P2 页面通过同工作区内的可空 `parentId` 建立树形关系，具体事务与软删除规则见 [子页面树契约草案](page-tree.md)。

P1 数据只保存在内存，刷新即重置；不把它命名为服务端保存或恢复草稿。Markdown 源码面板展示当前可导出结果，包含尚未持久化的编辑内容，不承诺逐字符还原原始 Markdown。导入前展示转换限制，原始输入必须仍可取得。

## P2 前必须冻结

- 文档 ID、工作区 ID 与内容独立；改名、移动不改变文档 ID。
- 服务端校验 schemaVersion、节点种类、属性、大小和结构深度；不只信任 TypeScript 类型。
- 遇到未知格式版本，拒绝写入并保留原数据，不自动初始化为空文档。
- 写入携带十进制字符串 expectedRevision；数据库用 bigint，事务内匹配后产生新的字符串 revision，冲突返回 409。
- API 错误区分认证失效、无权限、无效格式、资源不存在、冲突和服务不可用。
- 每次写入携带 UUID `clientMutationId`；服务端在同一事务中保留请求摘要和结果，超时后以同一标识重试或查询收据，不凭响应丢失推断未写入。
- 浏览器恢复草稿按用户、工作区、文档隔离，包含基准修订和格式版本。草稿不是备份。

后端当前有健康检查和可选账号接口，没有文档读写端点。此草案不表示上述服务端文档行为已经实现。
