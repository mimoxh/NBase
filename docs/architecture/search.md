# V1 页面搜索契约

当前搜索只查**已保存到服务端且未进入回收站**的页面标题与正文。IndexedDB 中尚未确认的草稿不会出现在结果中；历史快照也不在本期检索范围。

## 索引与迁移

- PostgreSQL 迁移 v3 给 `pages` 增加 `search_text`。迁移在同一事务中分批回填已有页面；回填或版本校验失败，服务不开放写入。回填不增加文档修订，也不改变 `updated_at`。
- 创建和修订更新在原有页面事务中同时写入 `search_text`。索引文字从经过校验的 Lexical JSON 提取：相邻格式化文字连续，块之间分隔；内部附件的文件名及替代文本可检索。节点键、链接目标 URL、内部附件 ID、未显示的 JSON 字段不作为正文索引。
- 软删除后立即从结果中排除；恢复后使用原有索引重新出现。历史与回收站阶段不通过清理附件来维护搜索。

## 查询与界面

- `GET /api/workspaces/:workspaceId/search?q=...&limit=...` 必须有有效会话和工作区成员身份，viewer 可搜索。查询按字面量进行不区分大小写的子串匹配，不把 `%`、`_` 当通配符；先列标题命中，再按最近更新排序。查询最长 100 个 UTF-16 单元、256 UTF-8 字节；`limit` 为 1～50，缺省 20。响应包含最多 `limit` 条摘要与 `truncated` 标记，不返回完整正文。
- 网页工作台显示标题、短摘要和 30 条上限提示。输入防抖 250ms；切换关键词会取消旧请求并忽略旧响应；中文输入法组词期间不提交搜索。空白、加载中、无结果、失败和重试有独立状态。`Ctrl/Cmd+K` 打开搜索。
- 打开结果走现有页面切换路径，当前编辑先进入本机草稿和保存队列。标题命中聚焦标题；正文命中仅移动 DOM 选区或滚动到内部附件，不修改 Lexical 文档。若页面在查询后改变，打开失败或词句在当前草稿中已不存在，给出提示，不覆盖当前编辑。

## 范围与性能

此方案无需额外搜索服务或分词字典，能检索中文连续词组、中英文混排和部分标题；暂不支持拼音、同义词、分词相关度、历史版本搜索。当前子串扫描适合先验证 V1 个人页面集合，不能仅凭本机两个页面推断大数据量性能。P3-06 需用多文档与长文档样例记录响应时间，再决定是否增加专用索引或搜索服务。
