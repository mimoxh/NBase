# 白板

白板是页面的一种（`pages.kind = 'whiteboard'`），画布内容存在页面已有的 `content_json` 里，因此直接复用修订号、`page_versions` 历史、回收站与恢复、操作收据、本机草稿、冲突另存和唯一保存路径 `usePageSaver`。没有新表，没有新运行时依赖；画布引擎自写。

## 数据契约

契约在 `packages/contracts/src/whiteboards.ts`，服务端与网页共用。

```jsonc
{
  "schemaVersion": 1,
  "editorState": { "root": { "type": "root", "version": 1, "children": [ /* 至多一个空段落 */ ] } },
  "board": { "elements": [ /* 按数组顺序即 z 序，从下到上 */ ] }
}
```

- `editorState` 固定为空正文，所以所有读取 `StoredDocumentContent` 的代码（Markdown、目录、版本对比等）看到的都是一个空文档，不会出错。是否是白板只看有没有 `board` 键（`isWhiteboardContent`）。
- 服务端规则：页面种类与内容形态必须一致。创建时带 `board` 的内容让新页面成为白板；更新时白板只能写白板内容、文档只能写文档内容，否则 `422 PAGE_KIND_INVALID`。白板下不能建子页面，也不能被选为移动目标。
- 元素类型：`shape`（rect / roundRect / ellipse / diamond / triangle，可带文字，`mindParentId` 存在即为思维导图节点）、`text`、`note`、`frame`、`image`、`card`（页面引用卡片）、`pen`（含 `highlighter` 标记）、`connector`。未知类型、未知字段一律拒绝。
- 盒状元素都有 `x, y, w, h, angle`（弧度，绕中心），可选 `locked`、`groupId`。画笔的点是相对左上角的扁平 x,y 数组，缩放时一起缩放。
- 连接线两端各有 `x, y`，可选 `bind: { elementId, ax, ay }`：`ax/ay` 是目标框内的归一化位置（0–1）。四边中点是固定锚点；其余位置（默认 0.5,0.5）按另一端的方向自动选边。绑定端的 `x, y` 只是保存时解析出的位置，用作目标缺失时的回退；渲染时永远以绑定目标为准，所以目标移动或缩放时连接线自动跟随，而不需要改连接线本身。
- 元素 id 是客户端生成的 UUID（小写），是持久身份；复制、粘贴、创建副本都换新 id，并重映射集合内部的引用（绑定、编组、导图父节点），指向集合外的引用会被断开（绑定端冻结为当前位置）。
- 视口、选择、当前工具、网格开关、小地图开关都是视图状态，**从不写进内容**；打开、平移、缩放、选择不会产生修订。

### 限制（`whiteboardLimits`）

| 项 | 值 |
| --- | --- |
| 元素数 | 5000 |
| 整个内容 JSON（UTF-8） | 1 MiB（与文档正文相同） |
| 文字 / 名称 / 标签长度 | 10 000 / 200 / 255 |
| 单笔画点数 | 4000 个点（8000 个数） |
| 坐标、尺寸 | 有限数，绝对值 ≤ 10 000 000，尺寸 ≤ 1 000 000 |
| 线宽、字号 | 线宽 ≤ 64；字号 4–400 |

颜色只接受 `#rrggbb`、`#rrggbbaa` 或 `transparent`。文字不得含控制字符（换行、制表除外）。禁止 `__proto__` / `constructor` / `prototype` 键。连接线不能绑定连接线或不存在的元素；导图父节点必须存在、是导图节点、且不成环。

## 服务端

- `apps/server/src/whiteboards/content.ts`：校验、搜索文本、附件引用和页面引用的白板分支。
- 现有文件只加了按内容形态分派的入口：`pages/validate.ts`（`validateDocumentContent`、`attachmentReferences`）、`pages/search-text.ts`（`inspectDocument`）、`pages/repository.ts`（创建时推断种类、更新时检查种类一致、白板不能做父页面）。
- 搜索：形状文字、便签、文本、框架名、连接线标签、图片文件名和卡片标签按 z 序拼进 `search_text`。
- 图片元素按文档附件的同一规则登记并校验（同工作区、文件名与类型一致），所以导出、回收与附件清理逻辑看到的引用与文档一致。
- 页面卡片写进 `page_links`（`occurrence` 是卡片序号，摘要是卡片标签），反向链接和关系图因此能看到白板引用；保存时目标页面必须存在于本工作区（回收站中的也算），否则 `422 PAGE_REFERENCE_INVALID`。
- 迁移 20（`whiteboard_pages`）只把 `pages_kind` CHECK 扩展为包含 `'whiteboard'`。版本 19、21、22 留给并行任务，迁移器允许版本号不连续。没有新表，`scripts/backup-engine.mjs` 无需登记。

## 网页

全部在 `apps/web/src/whiteboard/`，经 `lazy.tsx` 按需加载成独立分块；工作台只静态引用很小的 `host.ts`。

分层：

1. **纯模型**（无 DOM，vitest 覆盖）：`geometry.ts`（旋转、包围盒、多边形求交、折线路由、贝塞尔、笔画简化、对齐吸附）、`text.ts`（中西文混排换行，测量函数注入）、`model.ts`（命中、平移、八向缩放含旋转框、整体缩放与旋转、删除时解绑、复制重映射、z 序、编组、锁定、对齐/分布、样式、文字撑高、保存前规范化）、`mind.ts`（导图向右布局、插入子/兄弟节点）、`history.ts`、`clipboard.ts`。
2. **状态**：`store.ts`。写入只有三种：手势中 `preview`（不保存）、手势结束 `commit`（一步撤销 + 保存）、输入文字时 `persistPreview`（每次输入都保存草稿，但整段编辑仍只占一步撤销）。与上次保存逐元素相同的提交不会触发保存。
3. **渲染**：`render/canvas.ts`（Canvas 2D）、`render/paths.ts`（形状、笔画、连线、箭头都生成 SVG path 字符串，画布用 `Path2D`，SVG 导出直接写入，两边因此完全一致）、`render/colors.ts`、`render/export.ts`。
4. **交互**：`controller.ts`，把指针/滚轮/键盘转成模型操作。
5. **界面**：`WhiteboardView.tsx` 与 `ui/`（工具栏、属性条、就地文字编辑、右键菜单、页面选择、缩放条、小地图、放映）。

### 为什么用 Canvas 2D

约 2000 个元素时，SVG/DOM 每个元素都是节点，平移缩放要整树重排重绘；Canvas 2D 每帧只画视口内的元素（按包围盒裁剪），小字号在远景下跳过文字，重绘由 rAF 合批（被遮挡的视图另有定时器兜底）。代价是文字编辑与无障碍需要 DOM 补位：编辑时在元素位置叠一个随旋转和缩放变换的 `textarea`，画布上隐藏该元素的文字；工具、属性和菜单都是普通按钮。导出 SVG 复用同一套路径数据，不依赖画布。

### 保存

白板通过 `onChange(boardId, content)` 交给工作台：持久化工作台把它包成快照交给 `markDraft`，之后与文档完全相同——先写本机草稿，串行提交并带 `expectedRevision`，只有服务端确认后才显示「已保存」，冲突走现有冲突卡片（白板冲突只提供下载 JSON 与另存副本）。标题与画布一起保存。演示工作台只存在会话里，图片用会话内的 object URL。

### 交互要点

- 平移：空格拖动、中键、抓手工具、触控板/滚轮；缩放：Ctrl/⌘+滚轮、触控板捏合、双指触摸、Ctrl+= / Ctrl+-、Ctrl+0（100%）、Shift+1（适合）、Shift+2（所选）。
- 工具：V 选择、H 抓手、S 形状、T 文本、N 便签、C 连接线、P 画笔、Shift+P 荧光笔、E 橡皮擦、F 框架、M 思维导图；图片与页面卡片在工具栏。
- 编辑：单击/Shift 单击/框选；拖动移动（吸附与参考线，按住 Ctrl 关闭吸附，Shift 锁定方向，Alt 拖动复制）；八向缩放（Shift 保持比例，Alt 从中心）；旋转（Shift 15° 步进）；方向键微移（Shift 10px）；Ctrl+D 副本、Ctrl+G / Ctrl+Shift+G 编组、Ctrl+Shift+L 锁定、Ctrl+] / [ 层级；Ctrl+C/X/V 复制剪切粘贴（同时写入纯文本，粘贴支持图片文件、NBase 页面链接和普通文字）；Delete 删除；Ctrl+Z / Ctrl+Shift+Z 撤销重做。
- 文字：双击或 Enter 编辑；输入法组字期间的输入只在组字结束时应用，组字中的 Enter 永不结束编辑。便签与形状随文字自动增高，自由文本随内容加宽。
- 思维导图：Tab 添加子主题，Enter 添加同级主题（根节点为子主题），删除节点连同子树。
- 放映：按框架在数组中的顺序逐页全屏展示（方向键、空格、Esc）。导出：整板或所选，PNG（2 倍）与 SVG（内嵌图片）。
- 只读（无写权限、阅读模式、历史与回收站预览）只能选择、平移、缩放、复制、导出、打开卡片。

## 已知缺口

- 没有协同编辑；多标签页同时编辑同一白板时靠修订冲突处理，不做合并。
- 连接线折线是固定形状的启发式路由，不绕开其他元素；不支持手动拖动折线中段。
- 编组不可嵌套，也不能「进入组内」单独选择组员（点击即选整组）。
- 思维导图只向右展开，不支持折叠、拖动重排或换父节点；拖动任一节点会移动整张导图。
- 自由文本不支持局部样式（整段统一字号、颜色、粗细）；形状文字不支持加粗。
- 橡皮擦按元素整体删除，不能擦除笔画的一部分。
- 跨工作区粘贴时，指向其他工作区页面的卡片会被跳过；指向其他工作区附件的图片会让保存被拒绝（`ATTACHMENT_INVALID`），需要重新上传。
- 搜索结果和反向链接打开白板后不会定位到具体元素。
- 页面级「复制页面」「另存为模板」「Markdown 源码」「下载 Markdown」对白板不提供；「下载」得到的是白板 JSON。
- 演示工作台的图片只在当前会话有效。
- 深色主题由浅色颜色在绘制时换算，导出固定用浅色主题。
