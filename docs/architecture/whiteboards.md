# 白板

白板是页面的一种（`pages.kind = 'whiteboard'`），画布内容存在页面已有的 `content_json` 里，因此直接复用修订号、`page_versions` 历史、回收站与恢复、操作收据、本机草稿、冲突另存和唯一保存路径 `usePageSaver`。没有新表，没有新运行时依赖；画布引擎自写。

## 数据契约

契约在 `packages/contracts/src/whiteboards.ts`，服务端与网页共用。

```jsonc
{
  "schemaVersion": 1,
  "editorState": { "root": { "type": "root", "version": 1, "children": [ /* 至多一个空段落 */ ] } },
  "board": { "elements": [ /* 按数组顺序即 z 序，从下到上 */ ] }
}
```

- `editorState` 固定为空正文，所以所有读取 `StoredDocumentContent` 的代码（Markdown、目录、版本对比等）看到的都是一个空文档，不会出错。是否是白板只看有没有 `board` 键（`isWhiteboardContent`）。
- 服务端规则：页面种类与内容形态必须一致。创建时带 `board` 的内容让新页面成为白板；更新时白板只能写白板内容、文档只能写文档内容，否则 `422 PAGE_KIND_INVALID`。白板下不能建子页面，也不能被选为移动目标。
- 元素类型：`shape`（rect / roundRect / ellipse / diamond / triangle，可带文字，`mindParentId` 存在即为思维导图节点）、`text`、`note`、`frame`、`image`、`card`（页面引用卡片）、`pen`（含 `highlighter` 标记）、`connector`。未知类型、未知字段一律拒绝。
- 盒状元素都有 `x, y, w, h, angle`（弧度，绕中心），可选 `locked`、`groupId`、`groupParents`。画笔的点是相对左上角的扁平 x,y 数组，缩放时一起缩放。
- 编组：`groupId` 是元素所在的最内层组，`groupParents` 从内到外列出它外面的各层组（只在嵌套时出现）。组本身不是元素，没有单独的记录；同一个组 id 出现在哪些元素上，哪些元素就是组员。
- 形状、便签、自由文本可带 `bold: true`（整个元素加粗）。导图节点另有 `mindCollapsed: true`（收起它下面的分支）、`mindSide: 'left'`（只用于根节点的直接子节点：这一支向左展开；缺省向右，更深的节点跟随所在分支）和 `mindLayout: 'down'`（只用于根节点：整张导图按组织结构图向下展开，此时子节点不带 `mindSide`）。
- 局部文字样式：形状、便签、自由文本可带 `runs: [{ text, bold?, italic?, color?, fontSize? }]`。各段 `text` 非空，按顺序拼起来必须与元素的 `text` 完全相同；`color` 是文档编辑器的调色板名（`gray` / `brown` / `orange` / `yellow` / `green` / `blue` / `purple` / `pink` / `red`），浅色、深色主题各取 `formats.css` 中同名变量的值；未写的字段沿用元素自身样式。只在确有局部样式时保存 `runs`：与元素样式重复的属性、空段会被去掉，相邻同样式段合并，全部相同时整个字段删除。没有 `runs` 的旧白板照常显示，打开时不会被改写。搜索、反向链接摘要、复制的纯文本都读 `text`，所以不受影响。整体改加粗 / 字号 / 颜色时，`runs` 里对应的字段让位给整体样式。
- 连接线两端各有 `x, y`，可选 `bind: { elementId, ax, ay }`：`ax/ay` 是目标框内的归一化位置（0–1）。四边中点是固定锚点；其余位置（默认 0.5,0.5）按另一端的方向自动选边。绑定端的 `x, y` 只是保存时解析出的位置，用作目标缺失时的回退；渲染时永远以绑定目标为准，所以目标移动或缩放时连接线自动跟随，而不需要改连接线本身。
- 连接线可带 `waypoints: [{ x, y }]`（画布坐标，至多 100 个）：用户放置的拐点。折线连接线有拐点时路线依次经过它们（相邻两点不在同一水平/竖直线上时补一个直角），两端只重算端点到第一个 / 最后一个拐点之间那一小段；没有拐点时自动路由。直线连接线的拐点就是折线的顶点；曲线不使用拐点。保存时去掉只重复自动路线的首尾拐点，所以绑定的元素移动后，靠近它的那段会重新规划，而用户手动定下的部分保持不动。
- 旧白板可能带 `bend`（中间一段的偏移）。它仍按原样显示，首次编辑路线时换成等价的 `waypoints`，有 `waypoints` 时不再保存 `bend`。
- 元素 id 是客户端生成的 UUID（小写），是持久身份；复制、粘贴、创建副本都换新 id，并重映射集合内部的引用（绑定、编组、导图父节点），拐点随位移一起平移，`runs` 原样复制；指向集合外的引用会被断开（绑定端冻结为当前位置；只复制导图的一支时，这一支的顶端成为新的根）。
- 视口、选择、当前工具、网格开关、小地图开关都是视图状态，**从不写进内容**；打开、平移、缩放、选择不会产生修订。

### 限制（`whiteboardLimits`）

| 项 | 值 |
| --- | --- |
| 元素数 | 5000 |
| 整个内容 JSON（UTF-8） | 1 MiB（与文档正文相同） |
| 文字 / 名称 / 标签长度 | 10 000 / 200 / 255 |
| 单笔画点数 | 4000 个点（8000 个数） |
| 坐标、尺寸 | 有限数，绝对值 ≤ 10 000 000，尺寸 ≤ 1 000 000 |
| 线宽、字号 | 线宽 ≤ 64；字号 4–400 |
| 编组嵌套 | 8 层（`groupId` 加至多 7 个 `groupParents`） |
| 每个元素的文字样式段 | 500 段 |
| 每条连接线的拐点 | 100 个 |

颜色只接受 `#rrggbb`、`#rrggbbaa` 或 `transparent`。文字不得含控制字符（换行、制表除外）。禁止 `__proto__` / `constructor` / `prototype` 键。连接线不能绑定连接线或不存在的元素；导图父节点必须存在、是导图节点、且不成环。`groupParents` 必须与 `groupId` 同时出现，是不重复的 UUID 且不含 `groupId`；`mindCollapsed` 只能出现在导图节点上，`mindSide` 只能出现在有父节点的导图节点上；`bend` 必须是合法坐标值；`waypoints` 每项恰好有 `x`、`y` 两个合法坐标；`runs` 不得有未知键、空段、非调色板颜色或越界字号，且必须拼出 `text`；`mindLayout` 只能是 `'down'` 且只能出现在根节点上。这些字段都是可选的，旧白板无需迁移。

## 服务端

- `apps/server/src/whiteboards/content.ts`：校验、搜索文本、附件引用和页面引用的白板分支。
- 现有文件只加了按内容形态分派的入口：`pages/validate.ts`（`validateDocumentContent`、`attachmentReferences`）、`pages/search-text.ts`（`inspectDocument`）、`pages/repository.ts`（创建时推断种类、更新时检查种类一致、白板不能做父页面）。
- 搜索：形状文字、便签、文本、框架名、连接线标签、图片文件名和卡片标签按 z 序拼进 `search_text`。
- 图片元素按文档附件的同一规则登记并校验（同工作区、文件名与类型一致），所以导出、回收与附件清理逻辑看到的引用与文档一致。
- 页面卡片写进 `page_links`（`occurrence` 是卡片序号，摘要是卡片标签），反向链接和关系图因此能看到白板引用；保存时目标页面必须存在于本工作区（回收站中的也算），否则 `422 PAGE_REFERENCE_INVALID`。
- 迁移 20（`whiteboard_pages`）只把 `pages_kind` CHECK 扩展为包含 `'whiteboard'`。版本 19、21、22 留给并行任务，迁移器允许版本号不连续。没有新表，`scripts/backup-engine.mjs` 无需登记。

## 网页

全部在 `apps/web/src/whiteboard/`，经 `lazy.tsx` 按需加载成独立分块；工作台只静态引用很小的 `host.ts`。

分层：

1. **纯模型**（无 DOM，vitest 覆盖）：`geometry.ts`（旋转、包围盒、多边形与椭圆求交、贝塞尔、笔画简化、对齐吸附）、`route.ts`（避障折线路由、经过拐点的路线、平移线段 / 拆分线段 / 删除与拖动拐角）、`text.ts`（中西文混排换行，含按段样式的排版，测量函数注入）、`runs.ts`（样式段的规范化、按范围改样式、随输入迁移样式）、`model.ts`（命中、连接线路线与缓存、平移、八向缩放含旋转框、整体缩放与旋转、删除时解绑、复制重映射、z 序、嵌套编组、锁定、对齐/分布、样式、文字撑高、收起分支后的可见集合、局部擦除笔画、形状与连接线转笔画、按搜索词或页面引用定位元素、保存前规范化）、`mind.ts`（导图向右 / 向左 / 两侧 / 向下布局，插入子/兄弟节点，收起，拖动换父节点、重排、脱离）、`history.ts`、`clipboard.ts`。
2. **状态**：`store.ts`。写入只有三种：手势中 `preview`（不保存）、手势结束 `commit`（一步撤销 + 保存）、输入文字时 `persistPreview`（每次输入都保存草稿，但整段编辑仍只占一步撤销）。与上次保存逐元素相同的提交不会触发保存。
3. **渲染**：`render/canvas.ts`（Canvas 2D）、`render/paths.ts`（形状、笔画、连线、箭头都生成 SVG path 字符串，画布用 `Path2D`，SVG 导出直接写入，两边因此完全一致）、`render/colors.ts`、`render/export.ts`。
4. **交互**：`controller.ts`，把指针/滚轮/键盘转成模型操作。
5. **界面**：`WhiteboardView.tsx` 与 `ui/`（工具栏、属性条、就地文字编辑、右键菜单、页面选择、缩放条、小地图、放映）。

### 为什么用 Canvas 2D

约 2000 个元素时，SVG/DOM 每个元素都是节点，平移缩放要整树重排重绘；Canvas 2D 每帧只画视口内的元素（按包围盒裁剪），小字号在远景下跳过文字，重绘由 rAF 合批（被遮挡的视图另有定时器兜底）。代价是文字编辑与无障碍需要 DOM 补位：编辑时在元素位置叠一个随旋转和缩放变换的编辑框，画布上隐藏该元素的文字。形状、便签、自由文本用纯文本模式的 `contenteditable`，里面的 span 与样式段一一对应，所见即所画；输入时不重建 DOM（不打断输入法和光标），只在改样式、打开编辑和缩放时按模型重绘。框架名和连接线标签仍用 `textarea`；工具、属性和菜单都是普通按钮。导出 SVG 复用同一套路径数据，不依赖画布。

### 绘制与性能

- 只有视口内的元素进入绘制。连接线先用不需要路由就能算出的外框（两端、绑定元素和路由可绕行的范围）裁剪，视口外的连接线不计算路线。
- 自动折线路线按连接线 id 缓存，比较的是路线真正依赖的值：连接线的模式、两端与拐点，绑定元素的类型、形状与几何，以及周围障碍的外框。保存、撤销和粘贴会重建元素对象，但没移动的连接线不会重新搜索。障碍按 512 单位的粗网格分桶，每次路由只看路线可能经过的区域，至多 48 个障碍、4 万次搜索扩展，超出就退回固定形状的路线。搜索缓冲区在各次路由间复用，估价函数计入无法避免的拐弯，结果仍是最优路线。
- 拖动、缩放等手势的中间状态被标记为临时状态：两端没动的连接线只要仍不被移动中的元素挡住，就沿用上一条路线，不在每次指针移动时重新搜索；被挡住时立即重新绕行。手势结束后的状态照常完整路由，所以松手后的路线与手势过程无关。
- 形状轮廓、笔画和连接线线条按元素对象缓存为 `Path2D`（椭圆用 `Path2D.ellipse`，不再拼多边形），换行结果按文字、宽度和样式缓存，和缩放无关，所以缩放时不再重新换行。
- 缩放或平移进行中，屏幕上小于 8 像素的文字画成灰条，停止后再画真实文字。
- 拖动、缩放时 React 外壳不重渲染：工具栏、属性条、缩放条、小地图、嵌入层、文字编辑框都用 `useBoard(store, key)` 只订阅自己显示的那部分状态。

### 保存

白板通过 `onChange(boardId, content)` 交给工作台：持久化工作台把它包成快照交给 `markDraft`，之后与文档完全相同——先写本机草稿，串行提交并带 `expectedRevision`，只有服务端确认后才显示「已保存」，冲突走现有冲突卡片（白板冲突只提供下载 JSON 与另存副本）。标题与画布一起保存。演示工作台只存在会话里，图片用会话内的 object URL。

### 交互要点

- 平移：空格拖动、中键、抓手工具、触控板/滚轮；缩放：Ctrl/⌘+滚轮、触控板捏合、双指触摸、Ctrl+= / Ctrl+-、Ctrl+0（100%）、Shift+1（适合）、Shift+2（所选）。
- 工具：V 选择、H 抓手、S 形状、T 文本、N 便签、C 连接线、P 画笔、Shift+P 荧光笔、E 橡皮擦、F 框架、M 思维导图；图片与页面卡片在工具栏。形状、文本、便签、连接线、框架、导图工具创建一个元素后回到选择工具；双击工具按钮可锁定（按钮右下角有圆点），连续创建，单击该按钮、换工具或 Esc 解除。窄屏上工具栏横向滚动，两端有渐隐和箭头提示还有更多工具，点击箭头滚动，切换工具时当前工具会滚进可视区。
- 一个鼠标按下手势的抬起事件丢失（窗口外松开、指针捕获丢失）时，下一次按下或捕获丢失会先结束上一个手势，不会卡住后续操作。
- 编辑：单击/Shift 单击/框选；拖动移动（吸附与参考线，按住 Ctrl 关闭吸附，Shift 锁定方向，Alt 拖动复制）；八向缩放（Shift 保持比例，Alt 从中心）；旋转（Shift 15° 步进）；方向键微移（Shift 10px）；Ctrl+D 副本、Ctrl+G / Ctrl+Shift+G 编组、Ctrl+Shift+L 锁定、Ctrl+] / [ 层级；Ctrl+C/X/V 复制剪切粘贴（同时写入纯文本，粘贴支持图片文件、NBase 页面链接和普通文字）；Delete 删除；Ctrl+Z / Ctrl+Shift+Z 撤销重做。
- 文字：双击或 Enter 编辑；输入法组字期间的输入只在组字结束时应用，组字中的 Enter 永不结束编辑。便签与形状随文字自动增高，自由文本随内容加宽。编辑形状、便签、自由文本时上方出现文字工具条：加粗（Ctrl+B）、斜体（Ctrl+I）、减小 / 增大字号、文字颜色（调色板与默认色）。有选中文字时作用于选中部分，没有选中时作用于全部文字；样式变化与输入一样每次保存，整段编辑仍只占一步撤销。新输入的文字沿用光标前一个字的样式。
- 编组：点击组员选中最外层的组；双击进入这一层（虚线框标出范围），此后点击选中里面的单个元素或更内层的组，可再双击继续深入。Esc 或点击组外退出一层 / 全部。进入组内后再编组，新组建在当前组里面；取消编组只拆掉当前这一层。
- 折线连接线：自动路线是正交路线，避开路线附近的形状、便签、文本、图片、卡片和数据库视图（框架和笔画不算障碍），用 A* 在障碍边缘生成的稀疏网格上搜索，每个拐弯另加代价，所以优先选拐弯少的绕法；路线不被挡住时保持原来的固定形状。选中后每一段中点有手柄，拖动即平移这一段（贴着端点的段会在端点处留一小段再拐过去），拐角处的圆点可拖动；第一次拖动就把当前路线定为手动拐点。双击段上或右键「在此添加拐点」在该处插入一对拐点，之后可把两半分别拖开；双击拐角或右键「删除此拐点」去掉它；右键「恢复自动路由」或属性条「复位」去掉全部拐点。按下后没有真正移动（3 像素内）不改变也不保存。直线连接线拖动段中点会拉出一个新顶点。
- 橡皮擦：工具栏上方可切换「整个元素」与「局部擦除」。局部模式把擦过的笔画部分去掉，剩下的每一段成为独立笔画（第一段保留原 id，绑定在它上面的连接线不会断开）。擦到普通形状（非导图节点）的轮廓或连接线时，先把它转成笔画：轮廓或线条保留原 id、颜色和线宽，箭头成为单独笔画，文字（含样式段）拆成位置不变的自由文本，然后照常擦除；只划过填充内部、没碰到轮廓的不会转换。整个手势只占一步撤销，第一次转换时提示一次。
- 思维导图：Tab 添加子主题，Enter 添加同级主题（根节点为子主题），删除节点连同子树。有子节点的节点在悬停或选中时显示收起按钮，收起后显示被隐藏的节点数，点击展开；被收起的节点及其连线不参与命中、框选、吸附、适合视图和导出。属性条的「方向」切换整张导图向右、向左、两侧或向下。向下（组织结构图）时子节点横排在父节点下方并居中，同一层的节点对齐在同一行，连线是直角括号形；收起分支后兄弟节点向中间收拢；拖动节点时按指针的左右位置决定插在哪两个兄弟之间，放在其他节点上换父节点，从导图里拖出的分支仍向下展开。拖动根节点移动整张导图；拖动其他节点时，放在某个节点上成为它的子节点，放在兄弟之间调整顺序，放到根节点另一侧换边，拖到离导图较远处（约 140 像素外）脱离成为新导图的根。
- 放映：按框架在数组中的顺序逐页全屏展示（方向键、空格、Esc）。导出：整板或所选，PNG（2 倍）与 SVG（内嵌图片），各有浅色和深色背景两种。
- 定位：从搜索结果打开白板时，选中并居中第一个包含搜索词的元素；从反向链接打开时，选中对应的页面卡片或数据库视图。目标在收起的分支里时临时展开（不保存）。找不到时只打开白板并提示。
- 只读（无写权限、阅读模式、历史与回收站预览）只能选择、平移、缩放、复制、导出、打开卡片。

## 已知缺口

- 没有协同编辑；多标签页同时编辑同一白板时靠修订冲突处理，不做合并。
- 手动拐点优先：有拐点的连接线不再避障，用户拖出的路线可以穿过其他元素；删除拐角时相邻段平移合并，也可能穿过元素。避障只在路线可绕行的范围内（两端外扩约 180 单位）搜索，超出搜索上限时退回固定形状的路线。
- 思维导图一次只能拖动一个节点（连同它的分支）换位置；向下布局只对整张导图生效，不能单独让某一支向下。
- 局部擦除把形状转成笔画后，填充、虚线样式和导图关系都不保留；导图节点不会被转换。
- 文字编辑框按浏览器排版显示混合字号，行高与画布的绘制可能有几像素的差别，结束编辑后以画布为准。
- 跨工作区粘贴时，指向其他工作区页面的卡片和数据库视图会被跳过。图片会从复制时的地址读取并重新上传到当前工作区，读取不到的（无权限、来源已删除、演示工作台刷新后）会被跳过并提示。
- 页面级「另存为模板」「Markdown 源码」「下载 Markdown」对白板不提供；「下载」得到的是白板 JSON。「创建白板副本」由网页读取内容后新建页面，不走服务端的 `/copy`（该接口只接受文档）。
- 演示工作台的图片只在当前会话有效。
- 画布的深色主题由浅色颜色在绘制时换算。

## 嵌套（2026-11-13）

- **嵌进文档**：正文节点 `whiteboard-view` 只保存白板页面 ID 和可选高度（240～1600），可位于顶层或折叠块、提示块内。画布内容仍在白板页面里，在文档里绘制不产生文档修订。Markdown 写成单独一行 `[白板](/?page=<id>#nbase-whiteboard-view[=<高度>])`。该节点计入 `page_links`，与页面引用共用出现序号和 DOM 标记。
- **画布上的活页面**：`card` 元素加可选 `view: 'preview'`，新元素 `database`（`databaseId`、可选 `viewId`）。两者由 `ui/EmbedLayer.tsx` 用 DOM 叠在画布上，随视口平移缩放；未激活时不接收指针，选择、移动、缩放仍由画布处理。双击或 Enter 激活，Esc 或点击画布退出；激活期间白板自身的快捷键停用。同屏最多挂载 12 个，屏幕尺寸过小或超出上限的由画布画标题卡片。
- **保存**：嵌入的页面经 `apps/web/src/embed/source.ts` 的 `EmbeddedPages` 读写。持久化实现走 `usePageSaver` 的同一条路径（本机草稿、修订检查、收据），状态按页面上报给嵌入块的角标；冲突时嵌入块变只读，需打开该页面处理。同一页面在同一标签页只有一处可写，其余只读并在保存后重新读取。
- **嵌套上限**：从当前页面起最多四层；目标已在祖先链上或超过层数时显示为链接卡片。
- **取舍**：DOM 嵌入始终盖在画布元素之上；PNG / SVG 导出时画成标题卡片；嵌套在卡片里的白板只读。
