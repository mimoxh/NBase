# 页面属性

2026-11-20。普通页面可以给自己定义属性，数据库行页面则通过「添加属性」给所属数据库加字段。本轮不做按属性筛选，也不接入关系图。

## 数据

- 契约在 `packages/contracts/src/pageProperties.ts`。`PageProperty { id, name, type, value, options? }`，类型只有 `text`、`number`、`date`、`select`。
  - 单选的取值是选项 ID，选项沿用数据库的 `SelectOption`；日期沿用数据库日期单元格的写法（`isDateCellValue`）。
  - `value: null` 表示属性存在但没有值。
- 限制（`isPageProperties`）：每页最多 50 个属性；名称 1–100 字，页内不区分大小写不能重名；`title`、`tags`、`date` 是保留名（front matter 已有含义）；文本最长 2000 字；每个单选最多 100 个选项；数字必须是有限数。
- 迁移 31 给 `pages` 和 `page_versions` 各加 `page_properties jsonb`。`pages` 上的 CHECK 约束要求它是数组，且只有 `kind = 'document'` 的页面能有值。整库备份会自动带上这一列，备份引擎无须登记新表。

## 接口

- `PageDocument.pageProperties` 只在普通页面返回（没有属性时为空数组）。
- `CreatePageRequest`、`UpdatePageRequest` 的 `pageProperties` 是整体替换，更新沿用 `expectedRevision` 与操作收据，每次修改产生普通修订并写入 `page_versions`。格式不合法返回 400 `INVALID_REQUEST`；行页面、数据库页面和白板传这个字段返回 `PAGE_KIND_INVALID`。
- 页面移入数据库成为行时清空属性。复制页面和从模板新建保留属性，目标父级是数据库时除外。
- 历史恢复同时恢复当时的属性；恢复到非普通页面时忽略。

## 搜索

`search_text` 在正文文字之后追加「属性名 属性值」（单选取选项名，空值只写名称）。创建、保存和历史恢复都在同一事务里重算（`pages/search-text.ts` 的 `documentIndexText`）；历史版本的搜索文本回填（`search/history-index.ts`）使用同一函数。拼音键由现有的触发器和后台回填跟进。从搜索结果打开页面时，正文里找不到搜索词就到属性区找，找到则滚动到那一行（行页面的字段同理）。数字按显示格式（如 `1,200.5`）比对，因此按原始数字搜到的结果可能只打开页面而不定位。

## 网页

- `database/PageProperties.tsx`（经 `database/lazy.tsx` 按需加载）显示在普通页面标题下方。每个属性一行，取值编辑器复用数据库的单元格编辑器，单选可以当场新建选项。日期编辑器以 `plain` 模式打开，只有开始、结束和时间：页面属性不进日历，也没有提醒，所以不提供重复和提醒。属性菜单可以重命名、改类型和删除；改类型时，能转换的值保留（如数字转文本、文本里的数字转数字），否则清空。
- 页头的「添加属性」打开 `database/AddPropertyPopover.tsx`：输入名称，选四种类型之一。名称问题（空、重名、保留名、超长）在面板里直接提示。
- 保存走工作台的 `updatePageMeta`，与图标、封面、标签一致：先等待在途正文保存，有未解决草稿或待确认操作时拒绝，再带 `expectedRevision` 提交。面板内部的修改按顺序串行提交。只读成员只能看，不能改。
- 行页面的属性区底部也有「添加属性」，用同一个面板，经 `state.saveSchema` 把新字段追加到数据库结构，表格视图随即出现新列。没有写权限时不显示。

## Markdown 导出与导入

- 导出：`addMarkdownFrontMatter` 在 `tags` 之后写入属性；单选写选项名，日期写字符串，数字写数字，没有值的属性不写；与保留元数据同名时以属性为准。行页面把能简单表示的字段值写进去：文本、网址、数字、日期、复选框，单选和多选写选项名。单页导出、冲突下载和文件夹 ZIP 都使用同一逻辑。
- 导入：front matter 里除 `title`、`tags`、`date` 以外的顶层标量键转为属性。数字转数字，符合日期写法的字符串转日期，其他字符串、布尔值和空值转文本。数组、对象、名称不合法、超出长度或数量上限的键继续作为元数据保留在根节点。单页导入和文件夹导入都在创建页面时带上属性；文件夹导入里成为数据库行的页面不写属性。
- 往返损失：单选导出为选项名，再导入会变成文本属性；行页面导出的字段值再导入也是普通页面属性，不会回到数据库字段。

## 已知限制

- 不能按属性筛选、排序，关系图也不显示属性。
- 属性只属于单个页面，没有跨页面共享的属性定义；同名属性在不同页面上互不相关。
- HTML 和 Word 导出不包含属性。
